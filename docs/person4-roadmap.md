# Reflex Roadmap

## Key takeaway
The current MVP architecture can grow incrementally without being replaced.

### Now — MVP
- Manual rider assignment
- Real-time Socket.IO status updates
- QR delivery confirmation
- Hive offline retailer creation and sync

### Next
- Idempotency keys for offline retries
- Central available-rider endpoint
- Socket reconnect and state reconciliation
- Better pending-sync error visibility

### Later
- Geo-based rider matching
- Rider workload balancing
- Delivery analytics
- SLA tracking
- Push notifications
- Stronger offline-first synchronization
